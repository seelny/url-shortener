URL Shortener - a simple service to shorten long URLs and track click statistics.


Setup: Ensure Docker is installed. In the project root directory, run:

sudo docker compose up

Usage: 
Open http://localhost,
paste a long URL into the input field and click "Shorten",
enter the short code (e.g., "1") into the statistics section to view the original URL and total clicks.

It's just a functional foundation here by the way.
